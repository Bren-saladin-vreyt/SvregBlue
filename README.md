# SvregBlue

Fabric client mod for Minecraft 26.2 that turns the world into a **blue hour**: deep ultramarine nights, navy shadows instead of black, icy highlights and blue distance fog. Built to sit next to [SvregSky](https://github.com/Bren-saladin-vreyt/SvregSky), works on its own too.

## Download
Every push to `main` publishes the jar:
https://github.com/Bren-saladin-vreyt/SvregBlue/releases/download/latest/svregblue-0.1.0.jar

Put it in `mods/` with Fabric API (and SvregSky if you want both).

## Settings
Options → **SvregBlue** (under the SvregSky button):
- **SvregBlue**: everything on/off
- **Jam Biru**: Senja + Malam (default) / Malam / Seharian
- **Kekuatan Biru**: 0-100%
- **Bayangan Navy**: how much black is lifted to navy
- **Kabut Ikut Biru**: blue distance fog
- **Lampu Tetap Hangat**: torches and fire stay orange
- **Kabut Biru** + **Ketebalan Kabut**: thick blue-hour fog (thinner indoors and in caves)
